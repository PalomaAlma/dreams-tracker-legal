# Supprimer son compte — Dreams Tracker

*Dernière mise à jour : 26 octobre 2026.*

Cette page explique comment supprimer votre compte Dreams Tracker et ce que
cela efface. Le détail de ce que l'application enregistre est dans la
[politique de confidentialité](privacy-policy.md).

## Comment supprimer votre compte

**Depuis l'application** (la façon la plus rapide) :
Réglages → Compte → **« Supprimer mon compte »**.

**Sans l'application** (si elle est désinstallée ou inaccessible) : écrivez à
**paloma.alma.6@gmail.com**, depuis l'adresse e-mail du compte Google que vous
avez utilisé pour vous connecter, avec l'objet « Suppression de compte Dreams
Tracker ». Nous supprimons le compte dans un délai d'un mois.

## Ce qui est supprimé

La suppression efface votre compte et **toutes vos données chez notre
hébergeur** (Supabase, en France) : vos fiches (projets, tâches, routines,
rituels, journal, humeur, lectures, recettes, listes de courses, budget,
événements), votre profil et votre semaine type, la copie de votre agenda, et
vos compteurs d'envois du jour.

## Ce qui n'est pas supprimé

- **Vos données sur votre téléphone** : elles restent sur l'appareil.
  Désinstallez l'application pour les enlever. Dans un navigateur, elles sont
  effacées avec le compte.
- **Vos fichiers dans votre Google Drive** (photos, vidéos, sons, documents) :
  ils sont dans votre compte Google, pas dans le nôtre. Pour les retirer :
  Drive → Paramètres → Gérer les applications → Dreams Tracker → Supprimer les
  données cachées de l'application.
- **Vos signalements** (« Signaler ou suggérer »), conservés dans un dépôt privé
  de GitHub : écrivez-nous à l'adresse ci-dessus pour les faire supprimer.
- **Ce que Google a reçu** si vous avez utilisé les suggestions par IA : nous ne
  pouvons pas l'effacer.

## Supprimer une partie de vos données

Sans supprimer votre compte, vous pouvez supprimer n'importe quel projet,
tâche, routine ou entrée depuis l'application. Un élément supprimé est d'abord
marqué comme supprimé, pour que vos autres appareils l'apprennent, puis
**effacé pour de bon au bout de 90 jours sur l'appareil et de 180 jours sur
notre serveur**. Supprimer l'entrée d'un média ne supprime pas son fichier,
qui reste sur votre téléphone et dans votre Drive.
